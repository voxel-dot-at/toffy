# Recorded link surface — the "no new coupling" half of P0-2.
#
# Every line is one toffy symbol a consumer links against, demangled, measured
# with `nm -D --undefined-only` on a built consumer. tools/consumer_build.sh
# diffs the current surface against this file and fails on **additions**: a
# consumer quietly starting to use another part of toffy is invisible to a green
# build, invisible to the test suite, and load-bearing the first time someone
# splits a release. Removals are reported and allowed — dropping coupling is the
# direction we want.
#
# Format:  <consumer>[@ref] <demangled symbol>
#
# Regenerate (do not hand-edit; the strings are the compiler's, not ours):
#
#   nm -D --undefined-only <consumer>.so | awk '$1=="U"{print $2}' \
#     | c++filt | grep 'toffy::' | sed 's/std::__cxx11::/std::/g' \
#     | sort -u | sed 's/^/toffy-oatpp /'
#
# std::__cxx11:: is normalised out because it is libstdc++'s ABI tag, not
# toffy's, and a toolchain upgrade would otherwise report the whole surface as
# new.
#
# Baseline: toffy-oatpp @ feature/toffy-upgrade (21e8ecb) against toffy
# v2.0.0-5-g2a8bf19, Release, gcc 13 / aarch64-linux-gnu, 2026-10-28. Measured,
# and it reproduces the 16 recorded in the upgrade notes for the pre-upgrade
# probe: the set of *what is used* did not change across Phase 1 — only
# FilterBank::add's signature did, from Filter* to std::shared_ptr<Filter>,

#
# `boxes` is an application: it ships two executables and no shared object, so

#   --link-target boxes --link-target compute_single_box

# checker, reported **0 toffy symbols**, diffed that against a baseline with no
# `boxes` lines in it, and returned PASS. That is not a green gate, it is a gate
# that never ran while claiming to; the zero-surface guard added alongside this
# baseline turns exactly that shape into rc 2.
#
# 22 of the 24 are `boxes` itself — the number the upgrade notes carry, and it
# reproduces. The other two, FilterBank::add(FilterPtr) and
# Filter::setLogLevel, come only from compute_single_box, the offline tool that
